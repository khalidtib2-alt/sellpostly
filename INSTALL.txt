SellPostly Checkout & Cart Sync Patch

Extract into the repository root, preserving src/, public/, scripts/, and tests/.
Includes previous support email/studio preview and product landing page fixes.

Order Now and Pay with USDC / USDT open the existing CryptoCheckout dialog directly, passing the shop config, public slug, exact quantity total and original item ID/quantity to BuyerOrderForm. Buyer details are collected by the existing form. Preview mode does not submit live orders. Configure the platform Polygon escrow wallet to enable live checkout; no real payment was made in verification.

The product and storefront use sellpostly_cart_<slug>, with isolated preview/snapshot keys. Previous v1 carts migrate automatically. Changes save synchronously; tabs and same-page instances sync, and focus, visibility and browser back/forward restore the latest quantities. Storefront initialization no longer clears the saved cart.

If your checkout has a misplaced duplicate root app/ folder, run:
node scripts/fix-duplicate-app.mjs
The guarded repair backs up the duplicate outside the repository. It refuses to move a root app with its own layout or files missing canonical src/app counterparts.
