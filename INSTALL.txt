SellPostly Affiliate Guardrails + Extension 1.0.4

INSTALLATION
Extract into the repository root, preserving src/, public/, scripts/, tests/ and chrome-extension/. This cumulative patch retains the prior independent catalogs, editorial/boutique templates, product pages, cart, COD, escrow and email changes.
If a misplaced duplicate root app/ exists, use the guarded backup helper:
node scripts/fix-duplicate-app.mjs

Run the idempotent migration BEFORE deploying the updated application:
npm run db:init
This adds shops.affiliate_disclosure, preserves existing disclosure text from affiliate_catalog, and verifies the new column. Use your own DATABASE_URL/environment configuration; no secrets are included.

npm run build
npm test
Deploy through your normal process. This work has not modified the original checkout, migrated live Neon or deployed.

DISCLOSURE EDITOR AND BANNER
The Affiliate settings now have three preset pills above the editable textarea: Multi-Network Default, Amazon + Multi-Network and Amazon Only. EN preset copy matches the requested wording. FR/AR presets are translated. Save Disclosure publishes through the existing Pro-gated shop endpoint, persisting both catalog JSON and the independent affiliate_disclosure column. Publishing the Personal catalog does not overwrite it.
The active disclosure appears above the Affiliate hero in public and preview views. Empty disclosure text displays the Multi-Network Default. Known preset wording is displayed in the visitor's current language; custom seller text remains as authored. Seller text is rendered as plain escaped text.

AMAZON PRICE AND CTA GUARDS
Amazon regional destination hosts and amzn.to are identified by parsed hostname, not by substrings in a query or path. Lookalike hosts such as amazon.com.evil.example do not match. Affiliate Amazon cards omit current price, compare-at price, computed discounts and promotional badges. They use Check Price on Amazon with nofollow/sponsored/noopener/noreferrer and retain the full affiliate tracking URL. Non-Amazon affiliate cards keep their existing price and discount presentation. Personal Seller checkout/pricing is unchanged.
The checks are host-based; they do not resolve arbitrary third-party redirect services. These are the requested product guardrails, not an affiliate-network approval workflow.

IMAGE GUARDS
Raw media-amazon.com, images-amazon.com and ssl-images-amazon.com URLs (including their subdomains) are replaced with owned category illustrations in Affiliate products, additional photos and hero images during validation/loading/publishing. Existing saved catalogs are therefore protected when rendered. Affiliate image editor fields substitute on blur and again on save, with the translated helper notice. Own device uploads and non-Amazon press-kit/review photo URLs remain available.
The extension's Affiliate destination substitutes a packaged local illustration before displaying the imported photo and passes a safe /demo-products/*.svg website path through the existing short-URL bridge. The worker also checks incoming image payloads. Affiliate tags are preserved. Personal destination behavior remains separate. Open Full Studio uses the corresponding website image URL, rather than a chrome-extension resource URL.
The source assets and image notice are bundled locally; no image generation/tracking API is used at runtime.

EXTENSION INSTALLATION
The bundle includes a standalone SellPostly-Extension-1.0.4.zip. Extract it, then use chrome://extensions -> Developer mode -> Load unpacked and select the folder containing manifest.json. For an existing unpacked install, reload the updated folder and verify version 1.0.4.
Version 1.0.4 retains only activeTab, scripting and storage permissions. Affiliate and Personal destination selectors, category/audience controls and EN/FR/AR with RTL are preserved. The default frontend is https://sellpostly.vercel.app; vercel.com remains blocked.
